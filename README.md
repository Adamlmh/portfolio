# 丘俊凯

一条可以走进去的个人简介。点门进入，滚动或按方向键沿走廊往前走，再点开每一扇门，看在校、实习和即梦这段时间做过的事。

走动、点门、沿走廊阅读的方式，受 [ITom 的 3D 作品集](https://github.com/ITomPoland/portfolio-itom) 启发。这个仓库里的画面、文案和代码都是重新写的，没有使用对方的模型、贴图或原文。

## 本地打开

需要 Node.js 20 以上。

```bash
npm install
npm run dev
```

浏览器打开终端里给出的本地地址。

## 怎么走

- 点门，或点下方纸条，进入走廊
- 滚动、拖拽，或按上下方向键前进和后退
- 点墙上的门，或按回车，打开这段经历
- Esc 关上，目录可以跳到任意一扇门

经历来自我的实习总结，页面上只保留适合放在个人简介里的部分。
